## Outstanding practical gates

Settings access during the eight-second hold and disablement are not yet
verified for the final candidate. Hosted failure captures showed that stock
`uiautomator dump` can suppress the service under test; the observer is being
replaced rather than treating its hierarchy as a production failure verdict.
API 35/36 call scenarios must also pass after final tooling integration.

Actual native libraries pass LOAD and APK ZIP alignment checks. Their RELRO
layout fails the literal documented formula; this warning is retained.

passed compatibility-off API 36 x86_64 16 KB runtime testing: exact native
executable mapping, public cubic/conic iteration, supported JNI conversion to
16 quadratic segments, Welcome launch, live app PID and checked final crash
evidence. The isolated tested implementation is 809d224; 3d4ee80 adds only PR/main
trigger filters. Integrated root native run [38164514288](https://github.com/beejsbj/speedbreaker/actions/runs/38164514288) passed at eb14946, alongside Android run 38164514369 and metadata run 38164514416. Subsequent failed-transfer hardening needs its own hosted verification. Parent compared all four packaged native-library hashes with
the verified release APK: every ABI matches byte for byte. ARM64 runtime remains
untested. An earlier unsupported pre-API-34 iterator stress path on API 36
crashed; it was removed and is not evidence against the supported app path.
An earlier launch was killed by the emulator's low-memory killer; the final
disposable AVD has an explicit 4 GB RAM budget, with memory receipts retained.

Play screenshots. A separate actual 1080×1920 RGB JPEG packet is in preparation.

and reports absent captures explicitly.
