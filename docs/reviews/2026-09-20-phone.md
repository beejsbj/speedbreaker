## Reproduced failures and changes

**Gesture Back:** the same injected left-edge swipe returned unprotected
Calculator to Home but left an unlocked Speedbreaker overlay present. Global
Back immediately released it. `7bb4316` registers the platform window Back
callback, retaining key handling; `f053c7b` adds the cleanup API guards found by
lint. Root review checked Android 16 AOSP's synchronous dispatcher/parent setup
inside `addView`. The calibrated phone regression is still required.

**Frozen countdown:** overlay 1034 remained visually on Breathe / 8 sec from
04:11:51 through 04:15. A screenshot confirmed the actual display. A neutral
tap did not advance it; Settings escape still worked. The repeatable probe
opens Settings to reset, goes Home, launches Calculator, waits 14 seconds
without input, and requires choices. At 04:18:56 and 04:19:11 the same new
overlay 1040 still showed Breathe / 8 sec; the probe exited 1.

The main-thread accessibility window/root queries are the leading suspect;
stalled Compose rendering and Samsung suspension are alternatives. Causation
has not been established. Diagnostic `e2bcb42` publishes current tick ages,
phase, overlay publication age/elapsed value and a stale-main-thread stack
through a silent local notification. It records no app identities, content or
usage history, uses no new permissions and writes no diagnostic files.
**Remove every `DEBUG-SB-TIMER` site and the diagnostic class before the final
acceptance build.**
