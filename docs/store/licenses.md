# Release license and dependency evidence

The Community flavor is the F-Droid/FLOSS audit target. Play adds Google Play Billing and needs a separate review. A declared dependency list is insufficient: `inventoryCommunityRelease` and `inventoryPlayRelease` resolve each release runtime classpath and save its full Gradle component graph, artifact filenames, extensions, and SHA-256 hashes in `app/build/store-inventory/<channel>/dependencies.json`. Platform/BOM components appear in the graph even when they have no artifact file. Paths to user machines are excluded.

Hosted Android CI builds unsigned APKs for both flavors and an unsigned Play AAB. Its inventory artifact contains `dependencies.json`, the original Maven POM files used for license evidence, `licenses.json` with each POM's direct license name and URL, parent POM evidence where a direct declaration is absent, `license-texts.json` and fetched text where a POM URL serves it, `manifest.json`, the raw `aapt` output, and `provenance.json`. POMs are read from Gradle's cache first, then Google Maven or Maven Central. `no_direct_pom_license` records a parent coordinate where present; that is **not** a license assertion. `pom_missing` and `invalid_pom` likewise require investigation. A POM URL may point to a license summary rather than full legal text; inaccessible or non-HTTPS URLs are marked in `license-texts.json`. The POM files and URLs are evidence, not an automated legal verdict.

The manifest check inspects the final unsigned APK with Android build tools `aapt`. It checks package `dev.burooj.speedbreaker`, version code 6, min SDK 26, target SDK 36, absence of `INTERNET`, absence of billing permission in Community, and presence of billing permission in Play. It also checks that the application is not marked debuggable. The raw `aapt` output is preserved for inspection. The script records no credentials or private signing keys. `provenance.json` records the checked-out Git HEAD and tree, APK/AAB hashes, run ID, and PR head SHA. For a pull request, Actions checks out a synthetic merge commit: `sourceHead`/`githubHeadSha` refer to that merge commit, while `pullRequestHeadSha` identifies the contributor's branch tip. Neither is a signing attestation.

Artwork and fonts are outside `releaseRuntimeClasspath`. The app's original icon and artwork are project-authored and covered by the repository's Apache-2.0 license. Brand export fonts under `docs/brand/fonts/` have their own license texts: Lato (`Lato-LICENSE.txt`, OFL 1.1) and Liberation Serif (`Liberation-LICENSE.txt`, SIL OFL 1.1). These design-source fonts are not claimed as packaged runtime artifacts. Review the actual APK resources separately for any future bundled artwork or fonts.

Replay: `python3 scripts/store_inventory.py self-test`; on a host with Android SDK, run `./gradlew :app:assembleCommunityRelease :app:inventoryCommunityRelease` then `python3 scripts/store_inventory.py collect --dependencies app/build/store-inventory/community/dependencies.json --output app/build/store-inventory/community`. The hosted workflow runs both flavors, verifies the APK, and retains evidence for 30 days. Inclusion in F-Droid or a store is not established by this inventory.
